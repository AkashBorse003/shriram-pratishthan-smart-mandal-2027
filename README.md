# श्रीराम प्रतिष्ठान चिंचवड — Smart Mandal 2027

Vercel + Supabase deployment-ready Smart Mandal Management System.

Features: member registration, unique IDs, receipts, aarti, notifications, admin dashboard.

Deployment: create a Supabase project and run `supabase/schema.sql`, then import this repository into Vercel and add SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY and ADMIN_PIN as environment variables.
